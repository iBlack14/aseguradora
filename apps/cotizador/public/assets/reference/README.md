# Recursos visuales de referencia

Estos SVG fueron descargados de la página pública de cotización de La Positiva para facilitar la etapa de prototipado y reemplazo visual.

Antes de publicar, sustituirlos por recursos propios o con licencia. La interfaz usa rutas relativas como `/assets/reference/soat_auto_desk.svg`, por lo que puedes reemplazar un archivo conservando su nombre o cambiar la ruta en `app/page.tsx`.

También se incluyen el banner desktop/mobile, logo, ícono de placa, ilustraciones de vehículo, beneficios, modal y recursos auxiliares descargados de la página de referencia.
